# LIVE NOTE — YouTubeライブ分析メモ

YouTubeライブ配信や通常のYouTube動画をアプリ内で再生し、気になった場面を再生位置付きのメモとして保存するWebアプリです。保存したメモの時刻や本文をクリックすると、その場面へすぐに戻れます。

外部フレームワークは使用していません。HTML、CSS、JavaScript、YouTube IFrame Player APIだけで動作します。

## ファイル構成

```text
youtube-live-memo/
├── index.html
├── style.css
├── script.js
└── README.md
```

## VS Codeで開く

1. VS Codeを起動します。
2. メニューの「ファイル」→「フォルダーを開く」を選びます。
3. `youtube-live-memo` フォルダーを選択します。
4. エクスプローラーに4つのファイルが表示されることを確認します。

## Live Serverで起動する

1. VS Codeの拡張機能から **Live Server**（Ritwick Dey）をインストールします。
2. `index.html` を開きます。
3. エディター右下の **Go Live** をクリックします。
4. ブラウザで表示されたページを使用します。

`index.html` をファイルとして直接開くのではなく、Live Server経由で起動してください。YouTube IFrame Player APIはネットワーク接続を使用します。

## YouTubeライブ側の準備

過去の位置へ戻る機能を使用するには、YouTubeライブ側で **DVRを有効** にしておく必要があります。DVRが無効な配信、配信者が埋め込みを禁止している動画、視聴権限が必要な動画では、一部またはすべての機能を利用できません。

## 動画の読み込み

「YouTube URL / 動画ID」欄に次のいずれかを入力し、「動画を読み込む」を押します。入力欄で Enter を押しても読み込めます。

- `https://www.youtube.com/watch?v=VIDEO_ID`
- `https://youtu.be/VIDEO_ID`
- `https://www.youtube.com/live/VIDEO_ID`
- 11文字の動画IDのみ

補助対応として、`/embed/VIDEO_ID` と `/shorts/VIDEO_ID` 形式も読み込めます。

## ローテーションを記録する

動画を読み込むと、映像の下にあるローテーション欄を操作できます。

- 自チーム・相手チームそれぞれのP1〜P6に、背番号や選手名を入力できます。
- 「1つ回す」「1つ戻す」で6人の配置を一括移動し、表示をR1〜R6へ切り替えます。
- 「初期化」は、現在の動画について両チームの入力とローテーション番号を消去します。
- 「折りたたむ」でローテーション欄を閉じ、映像をさらに大きく表示できます。
- 入力内容は動画IDごとに、このブラウザのlocalStorageへ自動保存されます。

ローテーション情報は分析者ごとに自由に扱えるよう、共有メモとは分けて端末内だけに保存します。同じ公開URLを別の端末で開いてもローテーション情報は共有されません。

## メモを保存する

1. YouTubeプレイヤーで動画を再生します。
2. 「気づきを記録」欄に自由な文章を入力します。
3. 必要に応じて「記録する位置」を選びます。
4. 「現在位置にメモを保存」を押します。

メモ本文、調整後の再生時間、保存日時、一意のID、動画IDが保存されます。保存に成功すると入力欄は空になります。

### 数秒前の位置を記録する

映像を確認してから文章を書くまでの遅れを補うため、次の位置を選択できます。

- 現在位置
- 5秒前
- 10秒前
- 15秒前
- 30秒前

初期値は「5秒前」です。たとえば再生位置が2分00秒のときに「5秒前」で保存すると、メモの位置は1分55秒になります。計算結果が0秒未満の場合は0秒になります。

## メモの検索・並び替え・編集・削除

- 検索欄に文字を入力すると、メモ本文を大文字・小文字を区別せず部分一致で絞り込みます。
- 検索欄を空にすると全件表示に戻ります。
- 再生時間の昇順・降順、保存日時の新しい順・古い順に並び替えられます。
- メモ本文、「位置へ移動」、または再生時刻をクリックすると、その位置へ移動して再生します。
- 「編集」を押すと本文を編集できます。変更を保存しても再生位置と保存日時は変わりません。「キャンセル」で元の表示に戻ります。
- 「削除」で1件ずつ削除できます。
- 「全件削除」は、現在選択している動画のメモだけを確認ダイアログのあとに削除します。

## 再生位置の操作

- 「5秒戻る」「5秒進む」で現在位置から5秒移動します。
- 「ライブ地点へ戻る」は、YouTube APIから取得できる動画時間の終端付近へ移動します。
- DVRの利用可能範囲外では、YouTube側で位置が補正されたり、移動できなかったりする場合があります。

## キーボードショートカット

| 操作 | ショートカット |
| --- | --- |
| 現在位置にメモを保存 | `Ctrl + Enter` |
| 再生・一時停止を切り替える | `Enter` |
| ライブ地点へ戻る | `Alt + L` |
| 5秒戻る | `Alt + ←` |
| 5秒進む | `Alt + →` |

`Ctrl + Enter`、`Alt + L`、`Alt + ←`、`Alt + →` は、inputやtextareaにフォーカスがあるときも動作します。`Enter` による再生・一時停止だけは、入力欄・textarea・selectにフォーカスがある間は無効になり、文字入力を妨げません。ボタンやリンクにフォーカスがあるときの `Enter` は、通常どおりその要素を操作します。

## CSV出力

現在選択している動画の保存済みメモを、選択中の並び順でCSVファイルに出力します。検索による絞り込みはCSVには適用されず、その動画の全メモが対象です。

CSVには次の項目が含まれます。

- 動画ID
- メモ本文
- 再生時間（秒）
- 表示用再生時間
- 保存日時（ISO 8601形式）

すべてのセルをダブルクォートで囲み、本文内のダブルクォートを重ねてエスケープするため、カンマ・ダブルクォート・改行を含むメモにも対応します。ファイルは日本語の文字化けを防ぐUTF-8 BOM付きです。

## 公開版の共有メモ

公開環境では、保存したメモを共有データベースへ記録します。同じ動画IDを読み込んだ利用者には、同じメモ一覧が表示されます。

- 公開URLを知っている人は、メモの閲覧・追加・編集・削除・全件削除を行えます。
- 合言葉やログインは必要ありません。
- メモの検索、並び替え、CSV出力も全員が利用できます。

## Cloudflare Pagesへの自動公開

`.github/workflows/deploy-cloudflare-pages.yml` により、`main` ブランチへ変更を送ると、静的ファイルだけを既存のCloudflare Pagesプロジェクト `volleyball-live-note` へ自動公開します。

GitHubリポジトリの「Settings」→「Secrets and variables」→「Actions」に、次のRepository secretsを登録する必要があります。

- `CLOUDFARE_ACCOUNT_ID`：CloudflareアカウントID
- `CLOUDFARE_API_TOKEN`：Cloudflare Pagesの編集権限を持つAPIトークン

シークレット値はコードやGitHub Actionsのログには記載しないでください。手動実行する場合は、GitHubの「Actions」→「Deploy to Cloudflare Pages」→「Run workflow」を使用します。

## Live Server版のlocalStorage保存仕様

- 保存キーは `youtubeLiveMemoApp.v1` です。
- ローテーションの保存キーは `youtubeLiveRotationTracker.v1` です。公開版とLive Server版のどちらでも、動画IDごとに端末内へ保存します。
- VS CodeのLive Serverで起動した場合、データはそのブラウザのlocalStorageに保存されます。
- 動画IDをキーとしてメモを分けて管理します。別の動画を読み込むと、その動画のメモ一覧に切り替わります。
- ページを再読み込みしたりブラウザを閉じたりしてもメモは残ります。
- localStorageのデータ形式、動画ID、本文、ID、再生時間、保存日時を読み込み時に検証します。不正な項目は無視し、アプリの処理を継続します。
- ブラウザデータを削除した場合、シークレットモードの保存領域が破棄された場合、または別のブラウザ・端末を使用した場合、メモは引き継がれません。必要に応じてCSVをバックアップに使用してください。

## 既知の制限事項

- YouTubeライブの過去位置へ移動するには、配信側でDVRが有効である必要があります。
- YouTube IFrame Player APIだけでは厳密なライブエッジ位置を直接取得できないため、「ライブ地点へ戻る」は取得できた動画時間の終端付近へ移動します。
- ライブのDVR保持範囲より古い位置は、YouTube側の判断で別の位置へ補正されることがあります。
- YouTube側で埋め込み禁止、非公開、年齢制限、地域制限などが設定された動画は再生できないことがあります。
- 自動再生はブラウザのポリシーでブロックされる場合があります。その場合はプレイヤー標準の再生ボタンを押してください。
- Live Server版のデータは端末内だけに保存され、公開版へ自動移行されません。
- 公開版では同じ動画IDのメモが全利用者に共有されます。個人用の非公開メモ機能はありません。
- ローテーション情報は共有されず、入力したブラウザ・端末だけに保存されます。
- 公開URLを知っている人は共有メモを編集・削除できるため、URLの共有範囲に注意してください。
- ブラウザやOSが予約しているキー操作とショートカットが競合する場合があります。

## 主なエラー表示

APIの読み込み失敗、プレイヤー未準備、無効なURL、動画再生エラー、空のメモ、DVR位置への移動失敗、localStorageの読み書き失敗、CSV出力失敗は、画面右上のトースト通知で表示されます。エラーが起きても、可能な範囲で他の操作を継続できます。
